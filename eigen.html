Hoe embed je een Bandcamp-release

  1. Ga naar je album of track op Bandcamp.
  2. Klik op "Share / Embed" en kies "Embed".
  3. Kopieer de iframe code die Bandcamp geeft en plak die in de release kaart in eigen.html of in je data-bestand als embed veld.
  4. Als je liever via de GitHub-webeditor werkt: upload je cover naar assets/images/, voeg een object toe aan data/releases.json met velden voor title, description en embed (iframe), en commit — de site zal de embed tonen.
